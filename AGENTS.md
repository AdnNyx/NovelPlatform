## 1. Project Overview

- **Project Name:** Web Baca Novel Publik
- **Objective:** A public web novel reading platform where all visitors (**Guest**) can read every novel and chapter for free without logging in, while personalization features (bookmarks, reading history, follows, notifications) and content management (Novelis & Admin) require authentication.
- **Core Concept:** Public reading is completely open; authentication is strictly for reader personalization and the internal author/admin portal.

## 2. Hard Guardrails (Non-Negotiable Architectural Rules)

Every line of code generated by the AI agent **MUST** enforce the following constraints:

1. **Zero Direct Frontend Access to Supabase:**
   - **STRICTLY PROHIBITED:** Installing or importing `@supabase/supabase-js` anywhere inside `frontend/`.
   - The Next.js frontend **MUST NOT** execute database queries or upload files directly to Supabase Storage. All data operations and file uploads (novel covers, PDFs, chapter images) **MUST** route through the Python FastAPI REST API (`/api/...`).
2. **Supabase as Pure Database & Storage (RLS Disabled):**
   - *Row Level Security* (RLS) on Supabase PostgreSQL **MUST BE DISABLED (`DISABLE ROW LEVEL SECURITY`)** across all tables.
   - The Python FastAPI backend connects using `DATABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY`, holding **100% responsibility** for authentication, Role-Based Access Control (RBAC), and resource ownership validation (`novel.author_id == current_user.id`).
3. **Animation & Performance Isolation per Next.js Route Group:**
   - **Public Pages `(public)`** (`/`, `/katalog`, `/novel/[slug]`, `/ranking`, `/login`, `/profil`): **MUST** use **Lenis** (*smooth scroll*) + **GSAP** (lightweight entrance/scroll animations).
   - **Reader Page `(reader)`** (`/novel/[slug]/chapter/[id]`): **STRICTLY PROHIBITED from loading Lenis or GSAP.** Use native browser scrolling to keep reading lightweight, responsive on mobile/desktop, and accurate for scroll-position tracking (`histories.last_position`).
   - **Staff Portal `(staff)`** (`/staff/...`): **STRICTLY PROHIBITED from loading Lenis or GSAP.** Use a clean, utilitarian, high-density dashboard layout.
4. **Hidden Staff Portal:**
   - Routes `/staff/login` and `/staff/verify-otp` **MUST NOT** be linked in the public navbar, public footer, or `sitemap.xml`.
5. **Mandatory Backend HTML Sanitization:**
   - All HTML content submitted from the Rich Text Editor or generated by the PDF-to-HTML pipeline **MUST** be sanitized on the backend (using `nh3` or `bleach`) before database insertion to prevent *Stored XSS*.

## 4. Roles & Access Control Matrix (RBAC)

### 4.1. Role Definitions
1. **`guest` (Unauthenticated):**
   - Can read all published novels and chapters, search, filter, sort, view rankings, view novel details, and read comments/ratings.
   - Cannot use personal features (bookmark, history, follow, notifications) or write interactions (comments, replies, ratings). Clicking any restricted action redirects to `/login`.
2. **`pembaca` (Reader — Google OAuth):**
   - Inherits all `guest` permissions, plus **Bookmarks (Bookshelf)**, **Reading History**, **Follow Novel**, **Notifications**, **Reader Profile**, and writing **Comments/Replies** & **Ratings/Reviews**.
   - Cannot upload novels or access `/staff/...` routes.
3. **`novelis` (Author — Staff Login):**
   - Inherits all `pembaca` permissions.
   - Can **Upload, Update, and Delete** only their own novels and chapters (`author_id == user.id`).
   - Cannot edit other authors' novels, manage users, or manage master genres/tags.
   - Dashboard route: `/staff/novelis/dashboard`.
4. **`admin` (Administrator — Staff Login):**
   - Inherits all `pembaca` and `novelis` permissions.
   - Can manage all novels (approve/reject/delete), manage all users (promote `pembaca` to `novelis`, deactivate, ban), manage master genres & tags, and moderate/delete comments.
   - Dashboard route: `/staff/admin/dashboard`.

### 4.2. Access Control Matrix

| Feature / Action | `guest` | `pembaca` | `novelis` | `admin` |
| :--- | :---: | :---: | :---: | :---: |
| Read Novels & Chapters | Yes | Yes | Yes | Yes |
| Search, Filter, Sort & Rankings | Yes | Yes | Yes | Yes |
| View Comments & Ratings | Yes | Yes | Yes | Yes |
| Write Comments, Replies & Ratings | No | Yes | Yes | Yes |

| Follow Novels & Notifications | No | Yes | Yes | Yes |
| Upload / Update / Delete Own Novels | No | No | Yes | Yes |
| Manage All Novels, Users, Genres & Moderation | No | No | No | Yes |

## 5. Dual-Track Authentication Architecture

### 5.1. Track 1: Reader Authentication (`/login`)
- **Visibility:** Public page accessible via the "Masuk" button in the main navbar.
- **Technical Flow:**
  1. User clicks **"Masuk dengan Google"** on `/login`.
  2. Google Identity Services returns an `id_token` to the frontend.
  3. Frontend sends `POST /api/auth/google` with payload `{ "id_token": "..." }`.
  4. Backend verifies the `id_token` against Google (`google.oauth2.id_token.verify_oauth2_token`) and extracts `google_id`, `email`, `name`, and `picture`.
  5. Backend queries `users`: if no record exists, it automatically creates a new user with `role = 'pembaca'` and `is_active = true`. If an existing user has `is_active = false`, reject with `HTTP 403`.
  6. Backend issues a **Reader JWT** (expiration: **7 days**) stored in an `HttpOnly`, `Secure`, `SameSite=Lax` cookie.
  7. **No password, no manual email form, and no OTP.**

### 5.2. Track 2: Staff Authentication (`/staff/login` & `/staff/verify-otp`)
- **Visibility:** Hidden internal portal; **no links in the public navbar or footer**. Staff accounts cannot be self-registered publicly; they are created or promoted by an Admin.
- **Step-by-Step Technical Flow:**
  1. **Step 1 — Credentials (`POST /api/auth/staff/login`):**
     - Staff submits `identifier` (`username` OR `email`) + `password`.
     - **Rate Limit:** Maximum **5 consecutive failed password attempts**; exceeding this locks the account for **15 minutes** (`HTTP 429`).
     - Backend verifies password hash and confirms `role IN ('novelis', 'admin')` and `is_active = true`. Users with `role == 'pembaca'` **MUST** be rejected even if a password matches.
  2. **Step 2 — OTP Dispatch:**
     - Upon valid credentials, backend generates a cryptographically random **6-digit numeric OTP**, stores its **hash** in `otp_codes` (`expires_at = now() + 5 minutes`), and emails the plaintext code to the staff member.
     - **OTP Throttling:** Resend cooldown is **60 seconds**, capped at **3 OTP requests per hour** per email.
  3. **Step 3 — OTP Verification (`POST /api/auth/staff/verify-otp`):**
     - Staff enters the 6-digit code at `/staff/verify-otp`.
     - Backend verifies hash match, `is_used == false`, and `expires_at > now()`, then marks `is_used = true`.
  4. **Step 4 — Token Issuance & Redirect:**
     - Backend issues a **Staff Access JWT** (expiration: **2 hours**) + **Refresh Token** via `HttpOnly` cookies.
     - Frontend redirects `novelis` to `/staff/novelis/dashboard` and `admin` to `/staff/admin/dashboard`.

## 6. Detailed Feature & Content Pipeline Specifications

### 6.1. Public & Reader Mode Features
- **Novel Catalog (`/katalog`):** Responsive grid of novel cards displaying cover (`2:3` aspect ratio), title, primary genres, status (`Ongoing` / `Tamat`), and average rating.
- **Search, Filter & Sort:** Search by title, author display name, or tags; filter by multi-genre and status; sort by *Terpopuler* (views), *Terbaru* (latest), and *Rating Tertinggi* (highest rated).
- **Novel Detail (`/novel/[slug]`):** Large cover, full synopsis, genres, tags, chapter count, total views, average rating + reviews list, ordered chapter list, "Mulai Baca" / "Lanjut Baca" CTA, plus Bookmark and Follow buttons.
- **Rankings (`/ranking`):** Tabbed leaderboards for *Mingguan* (Weekly), *Bulanan* (Monthly), and *Sepanjang Masa* (All-Time).
- **Reader Mode (`/novel/[slug]/chapter/[id]`):**
  - Client-persisted reading preferences (`localStorage`): font size, font family, line height, and reading theme (**Terang**, **Gelap**, **Sepia**).
  - Chapter navigation: *Prev Chapter*, *Next Chapter*, and *Daftar Chapter* selector.
  - Per-chapter comments section at the bottom supporting nested replies (`parent_id`).
- **Ratings & Reviews:** `1–5` star rating and optional written review on the novel detail page.

### 6.2. Personal Reader Features (Login Required)
- **Bookmarks / Bookshelf:** Four shelf categories: `sedang_dibaca`, `ingin_dibaca`, `favorit`, and `selesai`.
- **Automatic Reading History:** As an authenticated reader scrolls through a chapter, the frontend sends debounced scroll progress (`novel_id`, `chapter_id`, `last_position`) to `POST /api/histories` for 1-click resume.
- **Follow Novel & Notifications:** Navbar bell icon with unread badge displaying notifications for new chapters on followed novels (`chapter_baru`) and replies to user comments (`balasan_komentar`).
- **Reader Profile (`/profil`):** Edit `display_name`, upload avatar, and view personal Bookmarks and Reading History tabs.

### 6.3. Novelis Features & Dual Chapter Input Modes
The **Create Novel Form** (`/staff/novelis/novel/create`) includes: Title, Cover image (`JPG`, `PNG`, `WebP`), Synopsis, Genres (multi-select), freeform Tags, Status (`ongoing` / `tamat`), and a radio selector for **Chapter Input Mode**:

1. **Mode 1 — Manual Web Typing (TipTap Rich Text Editor):**
   - **Text Formatting:** Bold, Italic, Underline, Strikethrough.
   - **Headings:** Heading 1 (`h1`), Heading 2 (`h2`), Heading 3 (`h3`).
   - **Paragraph Alignment:** Left, Center, Right, Justify.
   - **Lists:** Bullet List (`ul`), Numbered List (`ol`).
   - **Blocks & History:** Blockquote, Horizontal Rule (`hr`), Undo, Redo.
   - **Media & Links:** Inline Image upload (uploads via `POST /api/chapters/upload-image` to `chapter-images` bucket), Hyperlink insertion.
   - **Actions:** Preview modal (matching Reader Mode typography), Save as Draft (`is_draft=true, is_published=false`), Schedule Publish (`published_at > now()`), and Publish Immediately.
   - **Output:** Clean HTML submitted to the backend.

2. **Mode 2 — PDF Upload -> Auto-Convert to HTML:**
   - **Upload:** Author uploads a PDF (`1 PDF = 1 Chapter` or multi-chapter) to `POST /api/chapters/upload-pdf`.
   - **Async Python Worker:** Backend stores the PDF temporarily in the `pdfs` bucket, generates a `job_id`, and runs extraction via FastAPI `BackgroundTasks` using **PyMuPDF (`fitz`)** / `pdfplumber`.
   - **Extraction & HTML Generation:** Extracts text blocks using font-size heuristics to map headings (`<h1>`/`<h2>`) vs body paragraphs (`<p>`), extracts embedded images into the `chapter-images` bucket with `<img src="...">` tags, sanitizes the resulting HTML, and deletes the temporary PDF from `pdfs`.
   - **Editor Review:** Frontend polls `GET /api/chapters/pdf-jobs/{job_id}` until completion, then loads the generated HTML directly into the **TipTap Manual Editor** so the author can review, refine, and click **Publish**.

## 7. Canonical Database Schema (Supabase PostgreSQL)

Use the exact DDL below for `supabase/migrations/001_initial_schema.sql`. Ensure RLS remains disabled on every table.

```sql
CREATE EXTENSION IF NOT EXISTS "pgcrypto";

-- 1. USERS
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    username VARCHAR(50) UNIQUE,                  -- Populated for Novelis & Admin
    email VARCHAR(255) UNIQUE NOT NULL,
    display_name VARCHAR(100) NOT NULL,
    password_hash TEXT,                           -- NULL for Pembaca (Google OAuth)
    google_id VARCHAR(255) UNIQUE,                -- NULL for Staff
    avatar_url TEXT,
    role VARCHAR(20) NOT NULL DEFAULT 'pembaca' CHECK (role IN ('pembaca', 'novelis', 'admin')),
    is_active BOOLEAN NOT NULL DEFAULT TRUE,
    failed_login_attempts INT NOT NULL DEFAULT 0,
    locked_until TIMESTAMPTZ,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- 2. MASTER GENRES & TAGS
CREATE TABLE genres (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name VARCHAR(50) UNIQUE NOT NULL,
    slug VARCHAR(60) UNIQUE NOT NULL
);

CREATE TABLE tags (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name VARCHAR(50) UNIQUE NOT NULL,
    slug VARCHAR(60) UNIQUE NOT NULL
);

-- 3. NOVELS
CREATE TABLE novels (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    author_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    title VARCHAR(255) NOT NULL,
    slug VARCHAR(280) UNIQUE NOT NULL,
    cover_url TEXT,
    synopsis TEXT NOT NULL,
    genres TEXT[] NOT NULL DEFAULT '{}',
    tags TEXT[] NOT NULL DEFAULT '{}',
    status VARCHAR(20) NOT NULL DEFAULT 'ongoing' CHECK (status IN ('ongoing', 'tamat')),
    is_approved BOOLEAN NOT NULL DEFAULT TRUE,
    total_views BIGINT NOT NULL DEFAULT 0,
    total_chapters INT NOT NULL DEFAULT 0,
    rating_avg NUMERIC(3,2) NOT NULL DEFAULT 0.00,
    rating_count INT NOT NULL DEFAULT 0,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- 4. CHAPTERS
CREATE TABLE chapters (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    novel_id UUID NOT NULL REFERENCES novels(id) ON DELETE CASCADE,
    chapter_number INT NOT NULL,
    title VARCHAR(255) NOT NULL,
    content_html TEXT NOT NULL,
    is_draft BOOLEAN NOT NULL DEFAULT FALSE,
    is_published BOOLEAN NOT NULL DEFAULT TRUE,
    published_at TIMESTAMPTZ,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE (novel_id, chapter_number)
);

-- 5. BOOKMARKS
CREATE TABLE bookmarks (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    novel_id UUID NOT NULL REFERENCES novels(id) ON DELETE CASCADE,
    category VARCHAR(30) NOT NULL CHECK (category IN ('sedang_dibaca', 'ingin_dibaca', 'favorit', 'selesai')),
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE (user_id, novel_id)
);

-- 6. HISTORIES
CREATE TABLE histories (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    novel_id UUID NOT NULL REFERENCES novels(id) ON DELETE CASCADE,
    chapter_id UUID NOT NULL REFERENCES chapters(id) ON DELETE CASCADE,
    last_position NUMERIC(5,2) NOT NULL DEFAULT 0.00,
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE (user_id, novel_id)
);

-- 7. FOLLOWS
CREATE TABLE follows (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    novel_id UUID NOT NULL REFERENCES novels(id) ON DELETE CASCADE,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE (user_id, novel_id)
);

-- 8. NOTIFICATIONS
CREATE TABLE notifications (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    type VARCHAR(30) NOT NULL CHECK (type IN ('chapter_baru', 'balasan_komentar', 'novel_update')),
    title VARCHAR(255) NOT NULL,
    message TEXT NOT NULL,
    is_read BOOLEAN NOT NULL DEFAULT FALSE,
    novel_id UUID REFERENCES novels(id) ON DELETE CASCADE,
    chapter_id UUID REFERENCES chapters(id) ON DELETE CASCADE,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- 9. COMMENTS
CREATE TABLE comments (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    novel_id UUID NOT NULL REFERENCES novels(id) ON DELETE CASCADE,
    chapter_id UUID REFERENCES chapters(id) ON DELETE CASCADE,
    parent_id UUID REFERENCES comments(id) ON DELETE CASCADE,
    content TEXT NOT NULL,
    is_reported BOOLEAN NOT NULL DEFAULT FALSE,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- 10. RATINGS
CREATE TABLE ratings (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    novel_id UUID NOT NULL REFERENCES novels(id) ON DELETE CASCADE,
    score INT NOT NULL CHECK (score BETWEEN 1 AND 5),
    review TEXT,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    UNIQUE (user_id, novel_id)
);

-- 11. OTP CODES
CREATE TABLE otp_codes (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    email VARCHAR(255) NOT NULL,
    code_hash TEXT NOT NULL,
    expires_at TIMESTAMPTZ NOT NULL,
    is_used BOOLEAN NOT NULL DEFAULT FALSE,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```
